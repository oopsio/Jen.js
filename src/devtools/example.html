Getting Started

  1. Open the DevTools with Ctrl+Shift+J (or Cmd+Shift+J)
  2. Interact with the components below to see live updates in DevTools
  3. Click on components in the tree to inspect their props and state
  4. Hover over components in the tree to highlight them on the page
  5. Search for components by name or props in the search box
  6. View logs, network activity, and performance metrics in the tabs
  7. Export component state with the 📥 button
