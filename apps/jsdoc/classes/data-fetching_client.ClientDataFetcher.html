    Class ClientDataFetcher

    Client-side data fetching utilities for browser and Preact components. Provides reactive data fetching with cache, retry, and suspense support.

    Features:

    • Automatic refetch on mount/dependency changes
    • Suspense integration for data boundaries
    • In-flight request deduplication
    • Optimistic updates
