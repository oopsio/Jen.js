# Introduction to Jen.js

Jen.js is a TypeScript-first web framework designed for building fast, lightweight static and server-rendered applications using Preact.

## What is Jen.js?

Jen.js combines the best aspects of modern web development:

- **TypeScript-First**: Built with TypeScript from the ground up for type safety and better developer experience
- **File-Based Routing**: Routes are automatically generated from your file structure, no configuration needed
- **Preact-Powered**: Leverages Preact for lightweight, high-performance component rendering
- **Zero Configuration**: Works out of the box with sensible defaults
- **Multiple Rendering Strategies**: Support for static site generation (SSG) and server-side rendering (SSR)
- **Minimal Bundle Size**: Produces incredibly small JavaScript bundles, often just kilobytes

## Core Concepts

### Static Site Generation (SSG)

Generate your entire site at build time. Perfect for blogs, documentation, marketing sites, and any content that doesn't change frequently.

### Server-Side Rendering (SSR)

Render pages on the server for dynamic content. Great for applications that need to fetch data per request or personalize content.

### Islands Architecture

Load interactive components only where needed. Serve static HTML for the rest of the page, reducing JavaScript shipped to browsers.

## Why Choose Jen.js?

### Performance

Jen.js prioritizes performance from the ground up:
- Ultra-small bundle sizes
- Efficient asset hashing and minification
- Smart code splitting
- Optimized for Core Web Vitals

### Developer Experience

- Type-safe TypeScript configuration
- Hot module replacement (HMR) in development
- Clear, minimal API
- Comprehensive error messages

### Production Ready

- Tested and stable
- Follows web standards
- Compatible with existing JavaScript ecosystems
- Deployable anywhere
