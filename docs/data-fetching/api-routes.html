API Routes

Build backend endpoints with pages/api/*.ts.

Jen.js supports API routes via the pages/api/ directory. Each file exports HTTP method handlers following the standard Fetch API conventions.

Creating an API Route

Route Mapping

Files in pages/api/ map to URL paths:

FileRoute
pages/api/users.ts/api/users
pages/api/posts.ts/api/posts
pages/api/auth/login.ts/api/auth/login

Supported Methods

Export any of these HTTP method handlers:

  • GET
  • POST
  • PUT
  • DELETE
  • PATCH
  • HEAD
  • OPTIONS
