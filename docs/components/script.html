<Script>

Manage third-party scripts with loading strategies and security controls.

The <Script> component controls when and how third-party scripts are loaded, with built-in security.

Import

Usage

Props

PropTypeDefaultDescription
srcstring—External script URL
idstring—Unique identifier (prevents duplicates)
strategy'beforeInteractive' | 'afterInteractive' | 'lazyOnload''afterInteractive'Loading strategy
dangerouslySetScriptsboolean—Required security acknowledgment
childrenComponentChildren—Inline script content

Loading Strategies

StrategyWhenUse Case
beforeInteractiveRendered synchronously in SSR HTMLCritical scripts (polyfills)
afterInteractiveInjected after client hydrationAnalytics, widgets
lazyOnloadDeferred via requestIdleCallbackNon-essential trackers
