isr.maxRetries3
isr.retryDelay1000
requireDangerouslySetScriptstrue

Config Loading

Configuration is loaded once at startup by the ConfigLoader. Nested objects like middleware and isr are deep-merged with defaults — you only need to specify the values you want to override.
