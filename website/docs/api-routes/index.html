API Routes

Create API endpoints directly in your Jen.js project using API routes.

Creating API Routes

Place files in pages/api/ to create API endpoints: 

pages/api/
├── hello.ts        → GET /api/hello
├── users.ts        → /api/users
└── posts/
    └── [id].ts     → /api/posts/:id

Basic API Route

import type { ApiHandler } from 'jenjs';

export const GET: ApiHandler = async (req) => {
  return {
    statusCode: 200,
    body: JSON.stringify({ message: 'Hello, World!' }),
  };
};

export const POST: ApiHandler = async (req) => {
  const data = await req.json();
  return {
    statusCode: 201,
    body: JSON.stringify({ created: true, data }),
  };
};

HTTP Methods

Define handlers for specific HTTP methods: GET, POST, PUT, DELETE, PATCH.

Reading Request Data

Query Parameters

const id = req.query.id; // ?id=123

URL Parameters

const id_param = req.params.id_param;

Request Body

const body = await req.json();

Headers

const auth = req.headers['authorization'];

Response Handling

JSON Response

return {
  statusCode: 200,
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ success: true }),
};

Error Response

return {
  statusCode: 400,
  body: JSON.stringify({ error: 'Bad request' }),
};

Dynamic Routes

// pages/api/users/[id].ts
export const GET: ApiHandler = async (req) => {
  const id_param = req.params.id;
  const user = await fetchUser(id_param);
  
  if (!user) {
    return {
      statusCode: 404,
      body: JSON.stringify({ error: 'User not found' }),
    };
  }
  
  return {
    statusCode: 200,
    body: JSON.stringify(user),
  };
};

Best Practices

  • Validate input data before processing
  • Use appropriate HTTP status codes
  • Implement proper error handling
  • Add authentication for protected routes
  • Use TypeScript for type safety
