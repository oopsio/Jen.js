Configuration

Configure your Jen.js project using jen.config.ts in the project root.

Basic Configuration

import { defineConfig } from 'jenjs';

export default defineConfig({
  projectName: 'My Site',
  description: 'My awesome site',
  
  build: {
    strategy: 'static',
    outDir: 'dist',
    minify: true,
    hashAssets: true,
  },
  
  dev: {
    port: 3000,
    host: 'localhost',
    hmr: true,
  },
  
  server: {
    port: 3000,
    host: '0.0.0.0',
  },
});

Build Options

strategy

Choose between static generation or server-side rendering. Use 'static' to generate static HTML.

outDir

Output directory for built files. Default is 'dist'.

minify

Minify JavaScript and CSS. Enabled by default.

hashAssets

Add content-based hashing to asset filenames for cache busting.

Development Options

port

Development server port. Default is 3000.

host

Development server host. Use '0.0.0.0' for network access.

hmr

Enable hot module replacement for live reloading.

Routes Configuration

routes: {
  basePath: '/',
  trailingSlash: true,
}

Environment Variables

Create .env file:

VITE_API_URL=https://api.example.com
VITE_APP_NAME=My App

Use in code:

const apiUrl = import.meta.env.VITE_API_URL;
