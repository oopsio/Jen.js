Preact Components

Jen.js uses Preact, a lightweight alternative to React. Components work similarly to React but with a smaller footprint.

Component Basics

Create components using JSX or functional components: 

export default function Button({ children, onClick }) {
  return (
    <button onClick={onClick} class="btn">
      {children}
    </button>
  );
}

Functional Components

Use hooks for state and side effects:

import { useState, useEffect } from 'preact/hooks';

export default function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}

Essential Hooks

useState

Manage component state.

useEffect

Handle side effects after render.

useContext

Access context values.

useCallback

Memoize callback functions.

useMemo

Memoize computed values.

Props and Destructuring

function Card({ title, children }) {
  return (
    <div class="card">
      <h2>{title}</h2>
      <div>{children}</div>
    </div>
  );
}

Styling

CSS Classes

Inline Styles

Event Handling

function Form() {
  const handleSubmit = (e) => {
    e.preventDefault();
    console.log('Submitted');
  };

  return (
    <form onSubmit={handleSubmit}>
      <input />
      <button type="submit">Submit</button>
    </form>
  );
}

Performance Tips

  • Memoize expensive components with useMemo
  • Use useCallback for event handlers passed to children
  • Avoid inline function definitions in event handlers
  • Use lazy loading for large components
