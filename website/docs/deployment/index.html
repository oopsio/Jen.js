Deployment

Deploy your Jen.js application to production with various hosting providers.

Build for Production

npm run build

This generates optimized files in the dist/ directory.

Static Deployment

For static sites, upload the dist/ directory to any static host.

Vercel

npm install -g vercel
vercel

Or connect your GitHub repository for automatic deployments.

Netlify

npm install -g netlify-cli
netlify deploy --prod --dir dist

GitHub Pages

npm run build
git add dist
git commit -m "Deploy"
git push origin main

AWS S3

npm run build
aws s3 sync dist/ s3://my-bucket/

Cloudflare Pages

npm install -g wrangler
wrangler pages deploy dist

Environment Configuration

Production Environment Variables

Create .env.production:

VITE_API_URL=https://api.example.com
NODE_ENV=production

Performance Optimization

Caching Headers

Configure your host to cache static assets for long periods:

  • /dist/_astro/* → Cache for 1 year
  • /dist/assets/* → Cache for 1 year
  • /index.html → Cache for 5 minutes

Monitoring

Error Tracking

Use services like Sentry to track errors in production.

Analytics

Integrate analytics to track page views and user behavior.

SSL/HTTPS

All major hosts provide free SSL certificates automatically.

Continuous Deployment

Set up GitHub Actions or GitLab CI for automatic deployments on every push.

Best Practices

  • Always build and test locally before deploying
  • Use environment variables for secrets
  • Enable SSL/HTTPS
  • Configure caching headers
  • Set up monitoring and alerting
  • Use a CDN for static assets
  • Implement database backups
  • Keep dependencies updated
  • Monitor performance metrics
  • Have a rollback plan
