Building Static Sites

Jen.js can generate fully static HTML files at build time, perfect for hosting on any static host.

Building Your Site

npm run build

This generates optimized HTML, CSS, and JavaScript files in the dist/ directory.

Build Process

The build process includes:

  • Route Scanning: Discover all pages from your file structure
  • Static Generation: Pre-render pages to HTML
  • Asset Processing: Optimize images, fonts, and other assets
  • Code Splitting: Divide code into optimal chunks
  • Minification: Reduce file sizes
  • Asset Hashing: Add cache-busting hashes to filenames

Static Generation

export default {
  build: {
    strategy: 'static',
    outDir: 'dist',
  },
};

Generating Routes

All routes in pages/ are automatically generated. For dynamic routes, export getStaticParams:

export async function getStaticParams() {
  return [
    {slug: 'first-post'} ,
    {slug: 'second-post'} ,
  ];
}

Output Structure

dist/
├── index.html
├── about/
│   └── index.html
├── blog/
│   └── post-1/
│       └── index.html
├── _astro/
│   └── client.abc123.js
└── assets/
    └── images/

Deployment

Deploy to any static host like Vercel, Netlify, GitHub Pages, or AWS S3.

Preview Output

npm run preview

This serves the dist/ directory and lets you test before deployment.
