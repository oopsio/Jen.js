File-Based Routing

Jen.js uses file-based routing, meaning your file structure automatically becomes your URL structure. No configuration required.

Basic Structure

src/
├── pages/
│   ├── index.tsx          -> /
│   ├── about.tsx          -> /about
│   ├── blog/
│   │   ├── index.tsx      -> /blog
│   │   └── [slug].tsx     -> /blog/:slug
│   └── api/
│       └── hello.ts       -> API route

Route Types

Static Routes

Create a file and it becomes a route. The file name maps directly to the URL path.

pages/about.tsx -> /about
pages/pricing.tsx -> /pricing
pages/contact.tsx -> /contact

Dynamic Routes

Use square brackets to create dynamic segments.

pages/blog/[slug].tsx -> /blog/post-title
pages/products/[id].tsx -> /products/123
pages/users/[username]/profile.tsx -> /users/john/profile

Catch-All Routes

Use ellipsis to catch all remaining segments.

pages/docs/[...path].tsx -> /docs/getting-started/setup
                           /docs/api/core
                           /docs/anything/goes/here

Route Parameters

Access dynamic parameters in your component:

export default function BlogPost({ params }) {
  const { slug } = params;
  return <h1>Post: {' '}{'{'}slug{'}'}</h1>;
}

Best Practices

  • Keep route names descriptive and lowercase
  • Use dynamic routes for variable content
  • Organize related pages in subdirectories
  • Use layouts to share structure between routes
  • Pre-generate static routes at build time when possible
